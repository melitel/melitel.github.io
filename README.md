# Melitel Apps — GitHub Pages

Готовий багатосторінковий сайт для `melitel.github.io`.

## Структура

- `/` — головна сторінка-портфоліо з чотирма банерами.
- `/apps/kyiv-fortune/` — Київська ворожея.
- `/apps/mental-math/` — Математика: множення, ділення.
- `/apps/count-master/` — Count Master: Bag of Marbles.
- `/apps/swift-river-catch/` — Swift River Catch.
- `/count-master-privacy/` — збережений шлях, який зараз вказаний у Google Play. **Перед публікацією вставте сюди затверджений текст політики.**
- `/app-ads.txt` — збережено без змін.

## Публікація

Завантажте вміст цієї папки в корінь репозиторію `melitel/melitel.github.io`. У GitHub Pages використовуйте `main / (root)`.

## Рекомендовані Website URL у Play Console

- `https://melitel.github.io/apps/kyiv-fortune/`
- `https://melitel.github.io/apps/mental-math/`
- `https://melitel.github.io/apps/count-master/`
- `https://melitel.github.io/apps/swift-river-catch/`

## Перед фінальним релізом

1. Замініть векторні ілюстрації для Math, Count Master і Swift River Catch на актуальні іконки та скриншоти, якщо хочете показувати реальний інтерфейс.
2. Після редизайну Math додайте нові скриншоти на його сторінку.
3. Перевірте опис Swift River Catch: він підготовлений як нейтральна чернетка за назвою застосунку, бо Google Play не віддав повний опис під час перевірки.
4. Вставте затверджену політику конфіденційності в `/count-master-privacy/`.
5. Для кожного застосунку краще мати окрему privacy URL, а не посилання на головну сторінку-портфоліо.
